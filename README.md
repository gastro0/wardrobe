# Форма — Telegram Mini App

Личный гардероб: фотографии и названия вещей, конструктор и сохранение образов, рекомендации по погоде.

Открывается внутри Telegram через бота. Создание бота, размещение и секреты описаны в [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).

## Возможности

- Профиль с именем и полом: мужской, женский или не определён. При первом открытии приложение предлагает заполнить профиль; на главной странице показывает приветствие по имени. Изменить данные можно кнопкой профиля в шапке.
- 14 основных категорий: футболки и топы, рубашки, блузки, свитеры и кардиганы, худи и свитшоты, брюки и легинсы, джинсы, шорты, юбки, платья, комбинезоны, верхняя одежда, обувь и аксессуары. Для мужского профиля скрыты платья, юбки и блузки. Старые категории автоматически отображаются в соответствующих объединённых категориях; фотографии, температурные диапазоны и образы сохраняются.
- Загрузка JPG, PNG и WebP до 8 МБ; название, цвет, категория, комфортная температура, защита от дождя и ветра.
- При добавлении вещи фон удаляется автоматически в браузере. Приложение показывает прозрачный предпросмотр и сохраняет PNG с обрезанными пустыми краями. Обработка использует [IMG.LY Background Removal](https://github.com/imgly/background-removal-js); модель и WASM-файлы обслуживаются самим приложением. При ошибке можно повторить обработку или выбрать другое фото.
- Редактирование и удаление вещей; сборка и редактирование образов из выбранных вещей.
- Поиск городов через Open-Meteo Geocoding, текущая погода и прогноз на пять дней. Обновление каждые 15 минут при открытом приложении и при возвращении во вкладку.
- Подбор учитывает ощущаемую температуру, вероятность осадков, дождь, снег и ветер. При нехватке подходящих вещей показывается неполный комплект и объяснение. Цвет и стиль остаются на выбор пользователя.
- Отдельно помеченный пример коллекции. Примеры не записываются в личный гардероб; пробные образы существуют до перезагрузки страницы.

## Данные

Vinext / React / TypeScript, Cloudflare Worker. D1 (DB) хранит вещи, образы, профиль и выбранный город. Фотографии хранятся в закрытом Supabase Storage или R2 (BUCKET); локально — на диске через эмулятор R2. Вариант без подключения R2 описан в TELEGRAM_SETUP.md. Сервер проверяет вход Telegram и выдаёт защищённую сессию. У каждого пользователя свой гардероб с ключом `telegram:ID`: вещи, фотографии, образы, профиль и город изолированы. Существующие записи `private-wardrobe` доступны только аккаунту, явно указанному в серверном `TELEGRAM_OWNER_ID`; по умолчанию их не получает никто. Локальный предпросмотр без токена доступен только на loopback-адресе. Все API требуют вход, изменяющие запросы также проверяют Origin.

Схема: db/schema.ts; миграции: drizzle/. Новые миграции генерируются командой npm run db:generate. Не редактируйте уже применённые миграции.

npm run build собирает приложение. Публикация в Cloudflare и настройка Telegram описаны в `TELEGRAM_SETUP.md`. Для личного некоммерческого использования ключ Open-Meteo не требуется; условия сервиса: https://open-meteo.com/en/terms.

Проверены: TypeScript, правила подбора для жары, дождя, ветра, мороза и неполного гардероба; реальные ответы прогноза и поиска города. Исходники фотографий примера: ASSET_SOURCES.json.
