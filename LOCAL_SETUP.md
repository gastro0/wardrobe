# Локальный запуск Forma Wardrobe

## Что нужно установить

1. Node.js 22.13 или новее.
2. npm, он ставится вместе с Node.js.

## Как запустить

Откройте терминал в папке проекта и выполните:

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run db:init
npm.cmd start
```

В Windows PowerShell используйте `npm.cmd`, если выполнение `npm.ps1` заблокировано политикой системы. Локальный профиль в `.sites-runtime/execution-profile.json` должен быть `portable`.

После запуска откройте адрес, который покажет терминал. Обычно это `http://127.0.0.1:8787`.

Для последующих запусков достаточно `npm.cmd start`. После изменений кода сначала выполните `npm.cmd run build`. Для разработки используйте `npm.cmd run dev`.

Команда `npm.cmd run db:init` применяет миграции только к локальной базе. Повторный запуск пропускает уже применённые миграции и сохраняет вещи и образы. Выполняйте её также после добавления новых миграций.

## Как продолжать разработку с Codex

Когда хотите внести правки, пришлите мне архив проекта или подключите репозиторий, в котором лежит эта папка. Я смогу продолжить с текущей версии, менять код, проверять сборку и помогать публиковать обновления.

## Важные детали

- Приложение хранит локальные данные через Wrangler/D1/R2 в папке `.wrangler/state` после запуска.
- Для загрузки погоды нужен интернет: виджет берёт прогноз с внешнего сервиса.
- Первая сборка загружает около 56 МБ данных удаления фона в `public/background-removal/1.7.0`. Повторные сборки используют сохранённые файлы. При необходимости подготовить их отдельно выполните `npm.cmd run images:prepare`. Фотографии обрабатываются в браузере и сохраняются с прозрачным фоном.
- Зависимости находятся в `node_modules` и остаются на компьютере после установки. Повторно скачивать их при каждом запуске не нужно. Если папка удалена, восстановите её командой `npm.cmd ci`.
